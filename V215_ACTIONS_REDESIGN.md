# Jobdesk V2.1.5 — Simplified Job Detail Actions

- Main task (e.g., Set files ready to print, Mark completed) is now a single full-width primary action.
- Priority is a small secondary chip; automatic urgency shows as a non-interactive Due soon · auto urgent indicator.
- Manually urgent jobs show an explicit Remove manual urgent priority action.
- Cancel confirmation, Move to Trash, and Admin-only Delete permanently now live under a collapsed More actions section.
- Original confirm dialogs and permissions remain unchanged; no destructive operation performed in release.
- Desktop/mobile adjustments with reduced visual noise and touch-friendly controls.
- No database, Edge API, Admin PIN, jobs or user data changes.
