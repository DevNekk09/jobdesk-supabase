# Jobdesk V2.1.4 — Differentiated progress palette
File preparation stages are color coded: Confirmed blue, Preparing Master Files violet, Master Files Ready cyan, Prepare Set Files amber, Set Files Ready to Print teal. Unconfirmed stays warm yellow and Completed stays green.
Production stages are color coded: Review Files blue, Printing violet, Cutting orange, Sewing rose, Packing teal, Ready to Collect green.
Colors apply to job-list status labels, small segmented progress bars, File Preparation modal, Production detail chips, Production stage tabs/sidebar and Team Overview production track. Original stage labels and workflows stay intact for accessibility. Contrast enhanced with ink/dark text on pale backgrounds.
No database, API, Admin PIN, member or job data changes.
